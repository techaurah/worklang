## Variants

Each scenario is run 3 time(s) per agent: the scenario as shipped (variant 0) plus seeded variants. A variant shifts every seeded calendar busy block of the scenario by one seeded whole-hour offset, preserving layout; expected outcomes are never edited, and every variant is a real run through the unmodified runner. Names, budgets, and requested times live inside prose turns and are not perturbed in v0, because the scenario loader exposes them only as opaque strings.

## Channels

QualBench scenarios declare no channel, so every event in this corpus carries channel "unknown" rather than an invented one.

## Known schema gap

QualBench agents report two stage strings with no token in the WorkLang stage vocabulary (the ten LeadPipe stages plus none): HANDOFF and UNQUALIFIED. Neither is silently mapped into the stage stream. HANDOFF coincides with the handoff flag and surfaces as handoff events; a run whose final stage is UNQUALIFIED closes with outcome "lost". Whether these deserve stage tokens is a schema v2 question, recorded in DESIGN.md.
